Entry for the make.fun bounty [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa).

`main.py` (Python 3.13, standard library only) writes one single-line
pickup line, spoken to a Roomba, to `/output/entry.txt`:

> Roomba, you spent forty minutes under my couch hunting a sock I lost in March, so let me take you to dinner tonight, or at least buy you a new filter.

Run it with:

```sh
python3 -P -s main.py
```
